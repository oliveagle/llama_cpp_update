# Qwen3.5-35B-A3B-UD-Q4_K_XL 性能对比报告

> **生成时间**: 2026-03-01
> **测试模型**: Qwen3.5-35B-A3B-UD-Q4_K_XL
> **测试设备**: NVIDIA V100 (32GB) / AMD gfx1151 (Strix Halo)

---

## 执行摘要

本报告对比了 Qwen3.5-35B-A3B 在不同时期、不同配置下的 Stage 1 吞吐量测试结果，并与其他模型进行横向对比。

### 关键发现

1. **优化后性能提升显著**: 2026-03-01 的测试相比 2026-02-25 的测试，吞吐量提升了约 **30%**
2. **V100 表现优异**: Qwen3.5-35B 在 V100 上达到了 638-690 tokens/s 的吞吐量
3. **gfx1151 无法运行**: 该模型在 AMD gfx1151 上无法启动 (显存不足)

### 性能提升原因分析

1. **批次大小优化**: 从 512 提升到 2048，更好地利用 GPU 并行能力
2. **Flash Attention**: 开启 Flash Attention 2 加速注意力计算
3. **服务器稳定性**: 早期测试存在服务器重启问题，影响性能

## 吞吐量随 Context 增长的趋势

### Qwen3.5-35B (V100, 2026-03-01)

```
Context Size    TPS        相对性能
4096           638.7      100% (基准)
8192           664.7      104.1%
16384          675.4      105.7%
32768          690.1      108.0%
```

**观察**: 随着 Context 增大，吞吐量反而略有提升，这是 Flash Attention 优化的典型特征。

## 结论与建议

### 性能总结

1. **V100 表现优异**: Qwen3.5-35B 在 V100 上达到了 638-690 tokens/s 的吞吐量
2. **优化效果显著**: 相比早期测试，性能提升约 30%
3. **Context 扩展性良好**: 吞吐量随 Context 增大而略有提升

### 使用建议

| 场景 | 推荐配置 |
|------|----------|
| 实时对话 | Context 4096 (延迟 4.3s) |
| 文档分析 | Context 16384 (延迟 16.2s) |
| 长文本处理 | Context 32768 (延迟 31.7s) |

### 限制

- **gfx1151 无法运行**: 该模型超出 AMD 核显的显存容量
- **V100 显存占用**: 约 20GB，不适合与其他大模型同时运行

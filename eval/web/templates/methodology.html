测试规范与流程

llama.cpp 模型评估框架完整文档

Stage 1 - 基础能力

功能测试、上下文能力、性能基准测试

  • 模型加载验证
  • 4K-32K Context测试
  • 吞吐量测量
Stage 2 - 入门能力

代码、数学、文本、工具使用综合测试

  • 代码生成 (9项)
  • 数学推理 (11项)
  • 文本理解 (10项)
  • 工具使用 (20项)
Stage 3 - 综合能力

深度能力评估，65项全面测试

  • 数学推理 (10项)
  • 代码生成 (10项)
  • 逻辑推理 (10项)
  • 常识问答 (10项)
  • 文本理解 (10项)
  • Linux Shell (15项)

Context测试方法
大海捞针 (Needle in a Haystack) 测试
  1. 在长上下文的特定位置插入关键信息
  2. 要求模型回忆该信息
  3. 验证信息保留率
测试位置: 开头 / 中间 / 结尾
能力评估维度
数学推理 GSM8K、基础数学 准确率
代码能力 HumanEval、MBPP pass@1
逻辑推理 逻辑题、推理链 人工评估
常识问答 常识性问题 准确率
文本理解 阅读理解、摘要 ROUGE

执行命令参考
Vulkan 版本 (端口 8400)
# 1. 基础吞吐量 + Context 测试
python3 eval/eval_throughput.py \
  --model-url http://localhost:8400 \
  --model-name MODEL_NAME \
  --output-dir eval_results/vulkan/throughput

# 2. 综合能力测试
python3 eval/eval_all_capabilities.py \
  --model-path /path/to/model.gguf \
  --model-name MODEL_NAME \
  --model-url http://localhost:8400 \
  --output-dir eval_results/vulkan/comprehensive

# 3. Linux Shell 测试
python3 eval/eval_tools_capability.py \
  --model-url http://localhost:8400 \
  --model-name MODEL_NAME \
  --output-dir eval_results/vulkan/linux_shell \
  --linux

数据存档规范

每个测试必须保存以下文件:

eval_results/{backend}/{test_type}/
├── {model_name}_{test_type}_report.md    # 人类可读报告
├── {model_name}_{test_type}_raw.json     # 原始数据
└── {model_name}_{test_type}.log          # 测试日志 (可选)
目录结构
eval_results/
├── stage1/                    # Stage 1: 基础能力测试
├── stage2/                    # Stage 2: 入门能力测试
├── stage3/                    # Stage 3: 综合能力测试
├── vulkan/                    # Vulkan 后端测试结果
│   ├── throughput/           # 吞吐量测试
│   ├── context/              # Context 测试
│   ├── comprehensive/        # 综合能力测试
│   └── linux_shell/          # Linux Shell 测试
├── cuda/                      # CUDA 后端测试结果
└── reports/                   # 汇总报告

## 🚀 部署优化建议

### 1. 服务器配置

**最低要求**:
- CPU: Intel i5 8代或 AMD Ryzen 5 3代
- RAM: 8 GB (推荐 16 GB)
- GPU: NVIDIA GTX 1060 (6 GB) 或 AMD Radeon RX 580
- 存储: 10 GB 可用空间

**推荐配置**:
- CPU: Intel i7 10代或 AMD Ryzen 7 5代
- RAM: 16 GB (推荐 32 GB)
- GPU: NVIDIA RTX 3060 (12 GB) 或更好
- 存储: SSD

### 2. 性能优化

```bash
# 启动命令优化
./llama-server -m Qwen3.5-4B-UD-Q4_K_XL.gguf \
  --ctx-size 8192 \
  --n-gpu-layers 99 \
  --port 8080 \
  --threads 8 \
  --threads-batch 8 \
  --rope-freq-scale 0.75  # 支持更大上下文
```

### 3. 负载均衡

```nginx
upstream llm_backend {
    server 127.0.0.1:8080;
    server 127.0.0.1:8081;
    server 127.0.0.1:8082;
}

server {
    listen 80;
    server_name api.yourdomain.com;

    location /v1/chat/completions {
        proxy_pass http://llm_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
